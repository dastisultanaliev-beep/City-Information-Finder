
# City Information Finder

## Description
A simple desktop application built with Python and CustomTkinter.
It uses the Open-Meteo Geocoding API to find cities and display
their population and geographic coordinates.

## Features
- Search for cities by name.
- Display city population.
- Show longitude and latitude.
- Simple graphical interface.

## Technologies Used
- Python
- CustomTkinter
- Requests
- Open-Meteo Geocoding API

## Installation

1. Clone the repository:

   git clone YOUR_REPOSITORY_LINK

2. Install the required libraries:

   pip install -r requirements.txt

3. Run the application:

   python main.py

## Requirements
- Python 3.10+
- customtkinter
- requests
